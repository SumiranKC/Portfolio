# Portfolio

A responsive React portfolio for showcasing web development, graphic design, ML/AI, and other creative projects, plus work and education history.

## Run locally

```bash
npm install
npm run dev
```

## Personalise it

Most portfolio content lives in `src/App.jsx`:

- Replace the sample `projects` entries with real case studies and links.
- Update `experience` and `education` with your actual history.
- Replace the name, introduction, email address, and social links.
- Replace the résumé request link with a downloadable PDF when your résumé is ready.
- Connect the contact form to Formspree, EmailJS, or your own endpoint before publishing.

Create an optimised production build with `npm run build`.
